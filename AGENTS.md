# AGENTS.md

The engineering rules for this repository live in **[CLAUDE.md](CLAUDE.md)**, which is the single
source. Read that file.

This file exists only to point there, so the cross-tool `AGENTS.md` convention resolves to the
canonical rules. Nothing else belongs in it: rules copied here would drift from `CLAUDE.md`, and a
reader could not tell which copy an agent actually followed. (Decision 39 keeps `CLAUDE.md`
canonical because a `claude` session loads it automatically.)
